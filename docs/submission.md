# Submission Form Copy

## Brief (under 1,000 characters)
Civic Air Quality Briefing Studio helps Ward Officers, Housing Societies, and Schools turn messy pasted or uploaded air quality tables (mixed units, missing cells, broken sensors) into actionable local briefings. Users pick their role, advisory language (English or Hindi), and reading level (Simple or Standard), then paste, upload CSV/TSV, or tap an example table. Deterministic code assigns row IDs (R1..Rn), flags missing/out-of-range/mixed-unit readings, computes summary stats, and tracks numeric deltas against the previous brief. Gemini generates row-cited hotspot findings, prioritized role-specific actions, a "What changed" diff, a staff-only internal briefing note (unlocked via `/login` with demo credentials `staff` / `ward14demo`), and a copyable citizen advisory with extra care for children, older adults, and sensitive people.

## GenAI services used and where (under 1,000 characters)
Gemini API via the `google-genai` SDK in `ai.py` (`generate_briefing` and `_call_model`). Uses `gemini-3.5-flash` as primary model (`GEMINI_MODEL`) and `gemini-3.5-flash-lite` as single-retry fallback (`GEMINI_FALLBACK_MODEL`) with a 20-second timeout, 15-minute in-memory LRU cache, system instruction with `<DATA_TABLE>`/`<PREVIOUS_BRIEF>` delimiters, and Pydantic `BriefingResponse` structured JSON output (`response_schema`). Each call interprets messy tables, synthesizes row-cited hotspots and data gaps, tailors prioritized actions to the asking role, narrates changes since the previous brief, drafts the staff internal note, and writes the English/Hindi citizen advisory at the selected reading level. Deployed on Cloud Run (`pw-warmup`) with `GEMINI_API_KEY` from Secret Manager and JSON logs to Cloud Logging (`main.py`, `ai.py`).
